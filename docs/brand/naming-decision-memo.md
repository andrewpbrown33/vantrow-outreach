## 2. Detail — top 6 candidates

### 2.1 pitchrow — LOW — #1 pick

- **Rationale:** "Pitch" is the vertical's own object the way *eave* is roofing's and
  *parcel* is CRE's — it is what a seller *does*, in the seller's own vocabulary, across
  every channel (email pitch, call pitch, meeting pitch, agent-drafted pitch). One
  crisp syllable + `-row` reproduces the parent's exact shape (Vant-row / Pitch-row).
  Concrete, verbal, aspirational — the rep's word, not process jargon.
- **Sample tagline:** *"Pitchrow — every pitch, on time, in order."*
- **Domain status (2026-08-06):** pitchrow.com — Verisign RDAP 404 (**available**);
  pitchrow.io — rdap.org 404 + DNS NXDOMAIN/no NS (**available**, cross-checked).
- **Collisions (2026-08-06):** No entity named "pitchrow" anywhere — bare-string search
  returns only baseball coincidences (Pitchout; surnames Withrow/Myrow/Tedrow).
  Nearest neighbors, none confusable: **Pitchroom** (2-person pitch-sharing tool,
  Capterra/Tracxn-listed), **Pitch** (pitch.com, Berlin presentation software —
  sales-deck adjacent, different category), PitchBook (finance data). Doc-10 roster
  sweep: no house mark or sub-brand shares the root.
- **Trademark notes (2026-08-06):** No web-indexed PITCHROW filing found (method limits
  apply). Root neighbors: PITCHAGO (SN 90356868), PITCH COMEDY (Reg. 5602387, unrelated
  class). No in-class PITCH-formative registration for sequence/engagement software
  surfaced; note Pitch Software GmbH's possible EU/WIPO marks are invisible to this
  method — explicit counsel-checklist item.
- **Outreach similarity:** sound — none (PITCH-roh vs OWT-reech); appearance — none
  (shares no morpheme); meaning — overlaps only at the category level (both about
  selling), non-confusing. Groove/`-row` check: no g-onset, clears.
- **Endorsement fit:** "**Pitchrow, a Vantrow company**" — the strongest reading in the
  pool; near-rhyme with the parent, identical cadence to Eaverow/Parcelrow.
- **Biggest weakness:** the generic "pitch" root is crowded in *adjacent* deck/pitch
  tooling (Pitch.com, Pitchroom, PitchBook, Pitchago) — counsel must confirm none blocks
  class 9/42 sequence-software use; out of context the word can momentarily read
  baseball.

## 3. Ranked

1. **pitchrow** — *Why it wins:* the only candidate that is simultaneously risk-clean
   (no exact entity anywhere, no roster overlap, no formative filing surfaced), shaped
   exactly like the parent (1-syllable object + row), in the seller's own vocabulary,
   and unlimited in headroom (pitch spans email → calls → meetings → agents). *Biggest
   weakness:* generic-root crowding in adjacent deck/pitch tooling (Pitch.com,
   Pitchroom) — a counsel-checklist item.
2. **touchrow** — *Why it wins:* the most category-precise root (sequences are made of
   touches), channel-neutral, clean screens. *Biggest weakness:* abstract jargon root,
   plus the torchrow one-letter twin inviting typo/mishearing leakage.
3. **followrow** — *Why it wins:* cleanest screen of all 18 and names the product's
   guarantee (no dropped follow-ups). *Biggest weakness:* mid-sequence-only semantics
   and a passive connotation for a pipeline-creation brand.
4. **nudgerow** — *Why it wins:* distinctive human personality that matches the
   trust-first thesis; risk-clean in-industry (Nudge.ai is dead and absorbed by
   Affinity). *Biggest weakness:* lightweight enterprise register and a noisy
   NUDGE-formative namespace in other classes.

### #1 pick: **pitchrow**

Pitchrow beats touchrow because it trades a process word for the seller's own word: a
rep *makes pitches* — nobody says they "made touches" to a prospect — so the name sells
the act, not the plumbing, and does it in the parent's exact one-syllable-plus-row shape
("Pitchrow, a Vantrow company" scans identically to Vantrow itself). It carries none of
touchrow's typo-twin exposure (torchrow sits one letter away in our own pool), and its
screen came back as clean as followrow's while meaning far more at the top of the
funnel, where this product lives. Its one real caveat — the crowded generic "pitch" root
in *adjacent* tooling (Pitch.com presentations, the 2-person Pitchroom, PitchBook,
PITCHAGO SN 90356868) — is a **counsel-checklist item, not a blocker**: none of those
operate in sequence/engagement software, no in-class PITCH-formative registration
surfaced on 2026-08-06 (method limits apply), and both pitchrow.com and pitchrow.io were
registry-confirmed available the same day. Register the `.com` now; open the clearance
search with "confirm no in-class or EU/WIPO PITCH-formative conflict" as the first line.

**Adversarial pass (anatomy item 6):** (a) *"Pitch reads baseball."* — momentarily, out
of context; never in context ("Pitchrow for sales teams", app UI, endorsement line), and
the family's other roots (eave, parcel) carry the same out-of-context ambiguity. Accepted.
(b) *"Pitch.com will object."* — different category (presentations), different shape
(bare word vs compound), no US registration surfaced 2026-08-06; EU/WIPO check assigned
to counsel. Watched, not blocking. (c) *"'Pitch' is what spammers do — does it fight the
trust-first thesis?"* — "pitch" is neutral-professional in B2B ("pitch meeting", "pitch
deck"); the trust posture lives in product behavior and copy, not the noun. Accepted.
(d) *"Why not the category-native cadencerow?"* — because it is Salesloft's word
(§2.6): free-riding on a rival's vocabulary is the exact trap the outreachrow pre-flag
exists to catch, one tier down. Sustained — cadencerow stays counsel-gated at #6.
