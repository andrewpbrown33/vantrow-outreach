## 1. Positioning and tagline themes (paraphrased)

- **Current banner position (2026):** Outreach presents itself as an agentic-AI platform
  for revenue teams — the pitch is that AI agents act as extra teammates that can work
  every deal and account for every rep at once, so a team short on sales headcount no
  longer needs to hire more sellers. That staffing provocation is the homepage's lead
  theme. [S-OVW-001]
- **Category language:** it claims to be the only "revenue orchestration" platform
  covering prospecting, deal management, forecasting, coaching, and account expansion in
  one system. Note the shift from the older "sales engagement" / "sales execution
  platform" self-labels that still appear throughout the support glossary. [S-OVW-001]
  [S-OVW-005]
- **Rebrand:** the historical domain outreach.io now 301-redirects to outreach.ai; the
  April 2026 Omni press release explicitly frames the rename as signaling an AI-native
  platform. [S-OVW-002] [S-OVW-010]
- **Positioning arc (INFERENCE from dated sources):** sales engagement (glossary-era
  language, "Outreach Engage") → sales execution platform (glossary defines the
  platform this way) → agentic AI / revenue orchestration (2025-06 Unleash release and
  the 2026 homepage). The 2025 release quotes the CEO positioning AI as the platform's
  foundation rather than a feature. [S-OVW-005] [S-OVW-009] [S-OVW-001]
- **Recurring message themes:** consolidation (replace several point tools with one
  platform, e.g. the Amplitude story), rep productivity (hours saved, more pipeline per
  rep), and governed autonomy (agents run as co-pilot or auto-pilot under admin
  controls). [S-OVW-001] [S-OVW-004] [S-OVW-009]

- **INFERENCE:** the quote-only, per-user + AI-credit commercial model and the

### 3.4 The 2025–26 agentic-AI layer

- **June 2025 (Unleash):** an "AI Revenue Workflow Platform" generation with named
  agents — Outbound Prospecting, Expansion, Research, Conversation (meeting briefs),
  Deal (suggested CRM field updates), Reply (objection responses), Smart Forecast
  Assist, Smart Analytics Assist, Win/Loss Insights — each able to run as co-pilot or
  auto-pilot under governance and transparency controls. [S-OVW-009]
- **April 2026 (Spring release):** **Omni**, a universal conversational agent on Slack,
  mobile, and web (ask questions, analyze deals, send emails from one thread;
  conversations promotable to scheduled personal agents), and **Agent Studio**, a
  RevOps-facing builder that assembles custom agents from visual workflow templates.
  Supporting cast: Meeting Prep Agent, Deal Agent pushing field updates through Slack,
  Deal Alerts, AI Topics Explorer, Outcomes Report, Smart Kaia Coach, and **Outreach
  Knowledge**, which grounds agent output in company-approved content. An **Outreach
  MCP** surface is promoted on the homepage. [S-OVW-010] [S-OVW-001]

## 4. User roles model

Two orthogonal mechanisms control what a user can do: [S-OVW-006] [S-OVW-007]

- **Roles** form a reporting hierarchy (each role a node; parents oversee children
  transitively). Permission scopes like "owned and reports' records" resolve against
  this tree — e.g. a manager can act on records or mailboxes owned by anyone below
  them. Default roles are Admin, Manager, and Rep, extensible with custom roles
  *(snippet)*. [S-OVW-007] [S-OVW-008]
- **Governance profiles** are named permission sets (out-of-box: Admin — non-editable,
  Default, and Leadership *(snippet)*) covering 20+ areas: content create/edit/share
  for sequences/templates/snippets, admin functions (users, plugins, triggers,
  rulesets, branded URLs, export), ownership-tiered record visibility, email tracking,
  mailboxes, voice/SMS, integrations, Kaia/coaching/forecasting features. Managed under
  Administration > User Management > Access Control. [S-OVW-006] [S-OVW-008]
- **Teams** group users for views and data filters; **collections** group content for
  roles/teams (content governance). Seat accounting distinguishes locked (inactive, not
  consuming a seat) from unlocked users. [S-OVW-005]
- Distinct personas named by the vendor around the product: admin user (provisioning,
  sync, triggers, fields), content creator (builds sequences/templates/snippets), and
  ordinary reps; agent autonomy adds admin-set guardrails as a new governance surface.
  [S-OVW-005] [S-OVW-009]

## 5. Terminology glossary (our-words definitions)

All from the vendor's public glossary [S-OVW-005] unless noted.

| Term | Meaning (our words) |
|---|---|
| Prospect | The person (contact) being worked; carries emails/phones, timezone, stage, opt-outs, engagement counters |
| Account | The company a prospect belongs to |
| Sequence | An ordered multi-channel series of touchpoints (emails, calls, tasks) executed over time against enrolled prospects |
| Sequence step | One touchpoint in a sequence: auto email, manual email, call, LinkedIn task, SMS, or generic task |
| Sequence state | A prospect's live enrollment status in a sequence (pending, active, paused, paused-OOTO, disabled, failed, bounced, finished-replied, finished-no-reply, opted-out) |
| Prospect stage | A manually-managed field for buyer-journey position — distinct from the system-driven sequence state |
| Mailing | A single email send/receipt record with its own state (delivered, opened, clicked, replied, scheduled, bounced, unsubscribed) |
| Mailing type | How an email originated: one-off, bulk, or sequence |
| Ruleset | A reusable policy pack attached to a sequence: add/exclusivity rules, opt-out handling, stage automation, OOO behavior, engagement-triggered call tasks |
| Schedule | Admin-defined day/time delivery windows that gate when sequence emails send and tasks come due |
| Throttle | A cap on how many newly added prospects a sequence activates per 24 h |
| Trigger | Admin-built if-this-then-that automation reacting to events/conditions (auto-enroll, field updates, notifications) |
| Template | Reusable email content (subject+body+variables) used in sequence steps and one-off sends |
| Snippet | A smaller reusable text/image fragment inserted into emails or templates |
| Variable | Merge field pulling prospect/account/opportunity/sender data into content at send time |
| Collection | A grouping of content (templates, sequences, snippets) scoped to roles/teams for governance |
| Smart view | A saved, filterable list view over records |
| Engagement score | Weighted engagement measure over opens/clicks/replies used to prioritize prospects |
| Email sentiment | ML classification of replies: positive, objection, referral, unsubscribe, other |
| Persona | A prospect classification by attributes for targeting/messaging |
| Opt-out / granular opt-out | Unsubscribe overall or per channel (email/call/SMS) |
| Task | A queued action item (call, manual email, LinkedIn, generic) with priority and due time |
| Outreach Everywhere | Chrome extension embedding platform actions in Gmail/Salesforce (Outlook add-in is the O365 sibling) |
| Instance ("bento") | A customer org's hosted environment |
| Kaia / Commit / Voice / Engage | Nominative product names: conversation intelligence, forecasting, dialer, core engagement |
